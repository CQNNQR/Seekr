# Seekr v1.0.0 - Initial Release 🎉

**Release Date:** December 12, 2025

The first official release of Seekr - a fast, cross-platform disk usage analyzer!

## ✨ Features

### Disk Analysis
- Lightning-fast multi-threaded directory scanning
- Interactive tree view with folders sorted by size
- Real-time progress showing current directory being scanned
- Multiple visualization options: Pie charts, Bar graphs, and Treemaps
- Top Files view showing your largest files

### Duplicate File Finder
- Cross-drive duplicate detection (scan multiple folders at once)
- Smart HDD optimization using metadata fingerprinting
- Optional hash-based verification for 100% accuracy
- Bulk selection strategies: Keep Newest, Oldest, Shortest Path, Longest Path

### User Interface
- Modern Fluent design with Light and Dark themes
- Click-to-navigate charts (drill down by clicking)
- Context menus for Open, Reveal, Copy Path, Delete
- Search functionality to find files instantly
- Export to CSV or JSON

### Portable & Cross-Platform
- No installation required - just download and run
- Settings saved next to executable for USB portability
- Available for Windows, Linux, and macOS (Intel & Apple Silicon)

### Auto-Updates
- Check for updates with one click
- Download and install updates from within the app
- Settings and logs preserved during updates

## 🚀 Getting Started

1. Download the ZIP for your platform
2. Extract to any folder (or USB drive)
3. Run `Seekr.Avalonia.exe` (Windows) or `Seekr.Avalonia` (Mac/Linux)
4. Click "Select Folders" and start scanning!

## 📋 System Requirements

- **Windows:** Windows 10 or later (64-bit)
- **Linux:** Ubuntu 18.04+ or equivalent (64-bit)
- **macOS:** macOS 10.15 Catalina or later

## 🔒 Privacy

Seekr collects anonymous usage statistics to help improve the app. This includes:
- App version and platform
- Scan sizes and file counts (no filenames or paths)
- Feature usage (scans, duplicate detection)

You can disable telemetry in Settings → Privacy & Updates.
